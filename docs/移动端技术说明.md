# 移动端技术说明

## 技术构成

Android原生Java Activity与System WebView作为应用入口；React 19、TypeScript和Vite构建内置界面。MainActivity以同一已配置服务来源拦截主文档和/ui/资源，从APK assets加载文件；/api/请求继续交给电脑端。没有额外的移动端银行执行栈。

## 请求链路

移动端WebView → 私有网络网关 → FastAPI → 统一语义理解、知识检索与任务编排 → 业务工具与PostgreSQL。网页入口使用相同的后端服务。DAG表示步骤依赖，具体查账、还款等动作由业务工具执行。

## 原生适配

- 默认86%布局缩放，支持双指缩放；只在显示宽度改变时重算视口，键盘和回到前台不强制改阅读位置。
- Android系统文件选择器支持最多5张图片，每张不超过5MiB；只接受当前选择、当前来源下的内容URI。
- 文件选择结果在页面可见、应用已恢复且对应控件可用时回传，避免账号/来源切换后误投。
- 兼容脚本提供SHA-256、UUID、取消信号和剪贴板的有限兼容；随机数仍使用系统CSPRNG。

## 连接与安全边界

LocalOrigin仅接受私有IPv4或回环来源，拒绝地址中的账号口令和查询串。跨来源请求被阻止；用户主动点击的外部HTTPS链接交给系统浏览器。关闭WebView调试、文件跨域访问、混合内容和第三方Cookie；TLS错误直接取消。切换服务来源清除旧Web存储与Cookie。

客户端只声明网络访问与网络状态权限，没有相册全量读取、通讯录、定位或麦克风权限。模型API密钥保留在电脑端；资金权限、确认版本、幂等和账务检查由服务端统一执行。

本地HTTP连接缺少传输加密，因此仅适用于可信局域网；它不等于公开发布所需的HTTPS与独立身份认证。当前没有iOS安装包、离线业务执行或实体手机覆盖结论。
