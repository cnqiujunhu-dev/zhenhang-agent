# Android安装与电脑连接

APK内置网页资源，业务API、数据库和模型服务由电脑提供。安装APK后仍须按[部署说明](部署说明.md)启动电脑端。

## 设备与安装

- Android 9及以上。
- Android System WebView或Chrome 120及以上。
- 安装`mobile/dist`中的发行APK；先按校验文件核对文件未损坏。
- 当前发行版本为0.1.1。自行构建会生成新的签名，不能直接覆盖签名不同的原安装。

手机与电脑连入同一可信局域网。不要将电脑数据库端口或手机网关暴露到公网。

## Windows连接

在源码根目录的`mobile`文件夹双击“启动电脑服务.cmd”。也可以使用PowerShell：

```powershell
cd D:\ZhenhangAgent\mobile
.\Start-ComputerService.ps1
```

工具会检查电脑端服务，默认使用网页后端18965、手机网关18969。保持窗口打开，将它显示的完整私网地址填入APK。例如地址形式是`http://192.168.1.20:18969`，实际地址以本机工具输出为准。

指定网络接口或不同端口：

```powershell
.\Start-ComputerService.ps1 -Address 192.168.1.20 -BackendPort 18965 -Port 18969
```

脚本不会自动修改防火墙。若防火墙阻止连接，仅在可信局域网中，使用管理员PowerShell运行附带的`Allow-LanConnection.ps1`，显式指定本机地址与端口。它按本机子网限制来源，不应放宽为任意公网来源。

关闭网关窗口或按Ctrl+C只停止手机入口，不删除电脑端数据库。

## Linux / macOS连接

电脑端健康检查通过后，在源码根目录运行：

```sh
python3 mobile/android-client/lan_gateway.py --host 192.168.1.20 --port 18969 --upstream 18965
```

将示例IP替换为电脑实际私网IPv4，不能填`0.0.0.0`。网关使用Python标准库，不需要另装FastAPI。手动检查系统防火墙是否只允许可信局域网访问该IP和端口。Windows专用的PowerShell启动与防火墙脚本不适用于这些系统。

## 模拟器与USB

- 官方Android模拟器可尝试`http://10.0.2.2:18965`连接主机回环服务。
- 已安装Android平台工具并启用USB调试的设备，可执行`adb reverse tcp:18965 tcp:18965`，再在APK填写`http://127.0.0.1:18965`。
- APK的系统返回菜单或边缘手势可以重新打开连接设置。

## 连接后的核对

1. 先用电脑网页登录，确认账户可用。
2. 从电脑本地`app/var/private/首次登录.txt`取得初始口令，手机使用同一环境账户登录，查询银行卡和余额。不要将该文件上传到应用或共享。
3. 继续追问另一张卡或信用卡可用额度，确认金额来自同一后端。
4. 选择图片时先检查文件数量和大小，再由用户核对识别字段。图片模块固定请求`deepseek-flash`，与文字主模型分别验收；图片接口不可用时不以已有文字回复冒充提取成功。

本地网关当前使用明文HTTP，适用于可信局域网验证。自签名HTTPS错误不会被客户端忽略。网页更新不会自动替换APK中的固定资源；界面升级需要重新构建安装。
