# 第三方依赖说明

Python运行及开发依赖以`app/requirements.lock`、`requirements-dev.lock`、`requirements-build.lock`为准。前端依赖以`app/web/package-lock.json`为准。Dockerfile固定应用构建基础镜像摘要。

Embedding服务的直接依赖在`app/deploy/embedding.Dockerfile`中指定版本，其基础镜像标签和传递依赖尚未全部锁定。

主要依赖包括FastAPI、Pydantic、SQLAlchemy、psycopg、PostgreSQL、React、TypeScript、Vite和pgvector。各软件保持其原有许可，本包不改变其授权。

本机Embedding使用`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`，384维，实际模型文件集合的SHA-256在Compose中校验。首次启动下载权重，本包不附权重。Laya参考项目为https://github.com/NandhaKishorM/laya，属于可选实验接口。

当前仓库尚未确定统一开源许可证，源码供作品审查与复现使用。未另行授予自有源码许可证。React、ReactDOM、scheduler及@noble/hashes的许可见根目录THIRD_PARTY_NOTICES.md及licenses/。


## Android移动端

原生入口使用Android SDK与设备系统WebView，Java代码通过JDK 21编译。APK构建使用aapt2、D8、zipalign和apksigner；源码包不附SDK、JDK、模拟器或其许可证授权。

移动网页使用React、TypeScript、Vite，完整版本见mobile/web/package-lock.json。兼容脚本的SHA-256来自@noble/hashes 2.0.1，通过rolldown 1.2.11构建；两项直接依赖固定在mobile/Build-Android.ps1中，首次安装生成var目录下的依赖锁。保留源码中的版权及许可证标记，发布前按所用版本的许可证核对分发义务。

Android构建工具首次从官方地址下载固定组件，摘要检查由mobile/android-client/setup_toolchain.py执行。APK不包含独立聊天模型或Embedding权重。
