# 已知限制

- 外部银行清算、独立短信或设备认证、商户履约尚未全部接入。
- 同屏操作验证不是独立MFA。发布副本已明确用语，实际独立认证仍需接入。
- 图像提取使用外部视觉API，敏感材料需要用途、服务准入和保留期限管理。
- AA、会员权益、代扣和生日采购涉及合作方职责，应用内记录不替代外部回执。
- Laya前置分流未证明稳定提速，默认关闭。主模型依赖DeepSeek API可用性和余额。
- 历史37/37只覆盖18条样本的预标字段，不能推导所有字段或全业务完成率。
- 发布副本已在本机以独立Docker项目和新卷验证；其他电脑、操作系统、实体手机和容量上限仍需复验。
- Android 0.1.1使用固定网页快照，网页样式不会自动更新APK。HTTP网关仅用于可信局域网。
- 初始资料覆盖最近12个月，当前月份截至初始化时刻，不保证能做两个完整自然年度的同比。
- 源码不附运行库、用户对话、密钥或签名私钥。初始化不会覆盖已有环境。

股票和贵金属仅查询。产品节时、满意度和生产安全性尚无独立用户研究或第三方认证结论。
