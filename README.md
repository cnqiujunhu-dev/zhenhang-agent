# 圳行Agent · Zhenhang Agent

通过连续对话查询账户、分析账单、准备转账和信用卡业务，并在用户核对后执行。网页与 Android 应用共用同一套后端，结果来自业务查询和账务记录。

## 六场景

| 场景 | 主要功能 |
| --- | --- |
| 智能转账 | 收款人及卡片选择、连续补充、即时转账、预约与周期转账、AA |
| 账单分析 | 月度和年度账单、分类、退款、异常线索 |
| 理财操作 | 产品咨询、风险评估、持仓查询、申购与赎回 |
| 卡片管理 | 借记卡与双币信用卡、申请、锁卡、挂失、调额、还款和分期 |
| 订阅与代扣 | 价格咨询、已有服务、开通续订、自动续费设置 |
| 跨场景联动 | 查账后还款再复查、组合查询、家庭生日预算与有限授权 |

股票与贵金属仅提供查询。AA、商户会员和生日订单的外部合作接口仍需接入。当前应用内业务结果不代表真实银行清算或真实商户配送。

## 开始使用

电脑端使用 Docker Compose。首次启动需要联网下载镜像、依赖和 Embedding 模型，并配置有效的 DeepSeek API 密钥。无需本地聊天大模型或 GPU。

1. 将仓库或源码包解压到独立目录，准备 Docker 和 Python。
2. 按[部署说明](docs/部署说明.md)生成 `.env`、构建、初始化新环境并启动服务。
3. 打开 `http://127.0.0.1:18965/#/workspace`。
4. 登录后先看“用户资料”，使用本环境显示的卡号进行对话。
5. 需要手机入口时，再按[手机连接](docs/手机连接.md)安装 APK 并连接电脑。

初始口令在本机生成，不在仓库中共享。配置脚本生成后，打开电脑本地的 `app/var/private/首次登录.txt` 获取账户与初始口令；不要上传或分享该文件。推荐先使用 `wangwei` 体验，再用 `qiujunhu` 验证平台内转账收款；具体数据与账户规则见[样例数据](docs/样例数据.md)。

对话理解使用 `deepseek-v4-pro`。图片提取模块当前固定请求 `deepseek-flash`，两项能力需要分别验收；文字对话成功不代表图片模型已经可用。

## 工程结构

```text
zhenhang-agent/
  README.md
  app/                 API、Worker、业务模型、网页、部署与测试
  mobile/              Android入口、内置网页、APK、网关与构建脚本
  docs/                部署、数据、技术、测试和限制说明
  evidence/            经筛选的评测与验证数据
  SOURCE_MANIFEST.json 文件与来源校验信息
```

模型理解需求并提出动作，服务器检查原话、对象、权限和金额。DAG记录步骤依赖，具体查询与交易由业务工具完成。会话、确认、任务与账务保存在 PostgreSQL，公共知识另用独立数据库和 pgvector。

默认服务只绑定电脑回环地址。Android通过显式开启的私网网关访问，当前 HTTP 连接只用于可信局域网。公开部署前仍需完成独立认证、HTTPS、图像数据处理准入和外部业务接口验收。
