# 安装与连接

## 先启动电脑端

在源码根目录的app中生成新配置、填写模型凭据，并按部署说明启动Docker Compose。提交版网页默认为http://127.0.0.1:18965，数据卷与现有项目分开。

## 手机连接

1. 安装本目录dist中的0.1.1 APK。
2. 手机与电脑连入同一个可信局域网。
3. 在mobile目录双击“启动电脑服务.cmd”。工具显示当前电脑的局域网地址，默认端口18969。
4. 将工具显示的完整地址填入APK，连接后用电脑端账户登录。初次密码来自新部署生成的配置。

连接工具保留运行时，手机入口持续可用。按Ctrl+C只停止网关，不删除后端数据。右侧边缘向左滑或使用系统返回菜单，可重新打开连接设置。

工具不自动修改防火墙；被阻止时，可在管理员PowerShell中按实际端口运行Allow-LanConnection.ps1。仅用于可信私有网络，避免在公共Wi-Fi使用明文HTTP。

## 模拟器与USB

官方Android模拟器可尝试http://10.0.2.2:18965。USB调试设备也可在安装Android平台工具后运行adb reverse tcp:18965 tcp:18965，再在APK填写http://127.0.0.1:18965。USB调试与端口映射由设备持有人决定是否开启。

## 排错

- 电脑网页也打不开：先检查Compose健康状态和18965端口。
- 手机无法连接：检查同一网络、本机IP、端口和防火墙。输入框中的地址是示例，以启动工具的输出为准。
- 页面提示升级WebView：更新Android System WebView或Chrome后再连接。
- 模型请求失败：在电脑端核对API密钥、余额及模型权限，APK内不配置模型密钥。
- 本地HTTPS证书出错：客户端拒绝该连接，不忽略证书错误。
